# ADR 0013 — サイト設定は理解の文脈であり禁止ポリシーではない

日付: 2026-09-26。ユーザーの明示訂正に基づく。ADR 0010の提案領域／制作可否の強制部分を置き換える。

サイト基本情報、目標、技術・運営背景、施策の方向性は、サイトの性質を理解し分析・説明・仮説を有用にするための参考情報。設定単独で分析や提案を拒否せず、現在の明示依頼・条件を優先する。背景を無視するのではなく、実行上の難しさは仮説の前提や確認事項として説明する。

旧APIのtechnical_constraints、content_policy、allowed_surfaces、allow_new_content、allow_rewriteは保存互換のため残す。モデル向けには背景・関心を表すキーへ変換する。チェックOFFや空の領域は分析・提案の禁止ではない。旧レコード・revisionを一括書換えしない。

サイト説明はGA4の実測結果や新しいSemantic定義ではない。Property／Stream、Credential、Tool権限、期間・Filterの自動変更に使わない。認可、read-only、予算、根拠・登録指標の検証、会話の追加取得禁止は独立した従来の制御を維持する。設定から「確認済みの長期合意」を勝手に作らない。

当面の実装単位はQ3c-1: 全生成段階で共通のサイト理解文脈を共有し、誤った提案拒否とUIの許可表現を修正する。目的に応じた評価方法の高度化・実モデル比較はQ3c-2／3に分ける。
